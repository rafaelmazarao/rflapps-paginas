# rflapps-paginas

Páginas estáticas públicas dos apps da rflapps (política de privacidade e afins),
publicadas via GitHub Pages. Sem código de app nenhum aqui — só HTML estático.

- `/privacidade/` — Política de Privacidade do Garantia+ (`br.com.garantiaapp.app`).
- `/privacidade-meu-direito-plus/` — Política de Privacidade do Meu Direito+ (`com.meudireitoplus.meu_direito_plus`).
